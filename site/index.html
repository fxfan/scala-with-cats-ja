Functional Programming Strategies

In Scala With Cats

Functional Programming Strategies は、Scala with Cats の発展版である。 この新しい書籍の目標は、Scala with Cats における当初の目標──紙の書籍としての刊行と Cats 2 に対応する改定──を引き継ぎつつ、 著者が十年以上にわたって Scala によるソフトウェア構築に用いてきた要となる概念や技法をカバーすることである。 この試みがうまくいけば、本書を読むことで Scala を使う方はもちろん、他の関連する関数型言語を使う方も、 卓越したソフトウェアを構築するための道具を手にできるはずである。

こうした変更により本書の重点は型クラスから離れていき、 徐々に、旧タイトルではもはや内容を正確に表していないと感じるようになった。 そこで新たなタイトルが必要となった。 現在この本はプログラミング戦略というアイデアに焦点を当てているので、 Functional Programming Strategies とするのは当然の選択だった。 サブタイトルの In Scala with Cats は、本書の系譜を示すものであり、 型クラスや Cats におけるその実装に関する内容が引き続き含まれていることを表している。

Scala with Cats と本書を支えてくれたすべての方に感謝する。 長い道のりではあったが、読者にとってそれだけの価値があることを願っている。

Noel
